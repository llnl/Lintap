# Lintap

Lintap is a proof-of-concept host-based event sensor for Linux. Its goal is to
bring Wintap-style host event sensing to Linux.

## Getting Started

Clone the repository to review the project and contribute:

```sh
git clone https://github.com/LLNL/Lintap.git
cd Lintap
```
